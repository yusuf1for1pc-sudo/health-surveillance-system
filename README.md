# Tempest — Digital Health Records & Surveillance Platform

Tempest is a unified digital healthcare platform that enables secure medical record management while supporting real‑time disease surveillance for public health authorities.

The platform connects patients, doctors, healthcare organizations, administrators, and government agencies through a role‑based system that ensures secure data access, AI‑assisted clinical workflows, and anonymized population‑level health analytics.

By combining digital health records with surveillance analytics, Tempest helps healthcare providers deliver better patient care while enabling governments to detect disease outbreaks early and respond proactively.

## Implemented Features from Modified Problem Statement

Within the hackathon constraints, Tempest implements the following key components from the modified problem statement:

| PS Feature | Implementation in Tempest |
| :--- | :--- |
| **Unified Longitudinal Health Record (Health ID)** | Each patient receives a unique Health ID that links prescriptions, reports, and diagnoses across visits, creating a continuous medical history accessible to authorized providers. |
| **Live Disease Surveillance Analytics** | Diagnosis records are anonymized and aggregated to generate real‑time disease surveillance charts and geographic heatmaps for government dashboards. |
| **Digital Prescription Verification & Clinical Decision Support** | AI‑assisted clinical decision support analyzes doctor notes and symptoms to generate diagnostic suggestions, safety alerts, recommended tests, and precautionary treatment guidance. |

These capabilities demonstrate how patient‑level healthcare records can power privacy‑preserving public health monitoring systems.

## Core System Capabilities

### 🩺 Doctor Dashboard
Doctors can register patients and generate structured medical records including prescriptions, lab reports, and clinical notes.
The system integrates AI‑assisted ICD‑10 coding and clinical decision support to help doctors identify potential diagnoses and treatment precautions.

### 👤 Patient Portal
Patients can access their unified health history, including prescriptions, clinical notes, and lab reports generated by healthcare providers.
This creates a continuous digital health record across different medical visits.

### 🏥 Organization Management
Hospitals, clinics, and laboratories can register their institutions and manage medical staff access within the platform.

### 🛡️ Admin Panel
Platform administrators verify healthcare institutions and ensure that only authorized organizations gain access to the system.

### 📊 Government Surveillance Dashboard
The government analytics interface provides anonymized population‑level health insights including:
- Disease heatmap visualization across regions
- Real‑time disease trend monitoring
- Top reported diseases
- Regional outbreak distribution
- Early warning alerts for abnormal case spikes

These insights support proactive public‑health decision making.

## 🤖 AI‑Assisted Clinical Decision Support (CDSS)

Tempest includes an AI‑driven Clinical Decision Support System (CDSS) that assists doctors during diagnosis.
Based on symptoms and clinical notes entered by the doctor, the system generates:
- Possible diagnoses
- ICD‑10 classification codes
- Clinical risk alerts
- Drug safety warnings
- Recommended diagnostic tests
- Treatment precautions

The doctor always remains in control and can accept or dismiss AI suggestions.

## 👥 User Roles (Demo Login)

The platform supports multiple role‑based interfaces. From the login screen you can directly enter:

- **Patient**: View personal medical records and prescriptions.
- **Doctor / Medical Staff**: Create patient records, prescriptions, and clinical notes.
- **Organization**: Manage healthcare staff within hospitals or labs.
- **Admin**: Approve institutions and manage platform governance.
- **Government**: Access anonymized disease surveillance analytics and outbreak monitoring tools.

## Running the Project Locally

### 1. Clone the Repository
```bash
git clone https://github.com/yusuf1for1pc-sudo/health-surveillance-system.git
cd tempest-health-surveillance-system
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env` file in the root directory. Add the required environment variables without committing this file to the repository.

Example structure:
```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_GEMINI_API_KEY=your_gemini_api_key
```

⚠️ **Important:** Never commit your `.env` file or API keys to GitHub.

### 4. Run the Development Server
```bash
npm run dev
```
The application will start locally at: `http://localhost:5173`

## System Architecture Overview

Tempest follows a cloud‑native architecture designed for scalable healthcare systems.
- Patient records and medical events are securely stored in a relational database.
- Healthcare providers generate prescriptions and diagnoses through role‑based dashboards.
- Anonymized diagnosis data feeds the surveillance analytics engine, enabling real‑time disease trend analysis and geographic outbreak monitoring.
